# Artificial raster dataset representing grain sizes

The ratified raster dataset represents grain sizes with the three
classes clay, silt and sand, and WGS84 as a coordinate reference system.

## Examples

``` r
system.file("raster/grain.tif", package = "spData")
#> [1] "/home/runner/work/_temp/Library/spData/raster/grain.tif"
```
